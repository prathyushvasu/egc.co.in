ERFOLG PRIVATE LIMITED WEBSITE PACKAGE

FILES
- index.html: responsive main website
- privacy.html: draft privacy policy
- terms.html: draft terms of use

BEFORE PUBLISHING
1. Replace info@yourcompany.com in index.html, including the form's recipient address.
2. Replace +91 XXX XXX XXXX with the approved phone/WhatsApp number.
3. Add the verified office address and working hours.
4. Verify services, countries, licensing and company descriptions.
5. Review and complete privacy.html and terms.html with suitable professional advice.
6. Test the website and contact form on desktop and mobile.

FORM LIMITATION
The form opens a pre-filled email draft using the visitor's email application. It does not store or send data to a server and does not accept CV attachments. For a production form, connect a secure form service or server-side endpoint and add suitable privacy/security controls.

HOW TO PUBLISH
1. Purchase a domain and web hosting.
2. Upload index.html, privacy.html and terms.html into the hosting provider's public web folder (often public_html).
3. Keep the home page named index.html.
4. Connect domain DNS and enable HTTPS/SSL.
5. Test the live website on mobile and desktop.

This package does not itself register a domain, purchase hosting or publish the website online.
